# 🧪 Lab Results App

> Application web offline pour la gestion et l'édition des résultats d'analyses médicales.

## 📌 Description

Lab Results App est une application développée pour faciliter la saisie, la vérification et l'impression des résultats d'analyses de laboratoire.

Elle permet aux laboratoires de créer rapidement des comptes rendus d'analyses avec une mise en page professionnelle au format PDF.

## ✨ Fonctionnalités

✅ Gestion des informations patient :
- Nom
- Prénom
- Âge
- Sexe
- Numéro laboratoire
- Date d'analyse

✅ Domaines d'analyses disponibles :
- 🩸 Hématologie
- 🧬 Sérologie
- 🦠 Parasitologie
- ⚗️ Biochimie

✅ Fonctionnalités principales :
- Sélection des analyses
- Valeurs normales adaptées selon l'âge et le sexe
- Détection des valeurs anormales
- Exportation des résultats en PDF
- Fonctionnement hors connexion (Offline)

## 🧫 Analyses supportées

### Hématologie
- NFS
- Hémoglobine
- Globules blancs
- Plaquettes
- Etc.

### Sérologie
- VIH
- Hépatite B
- Hépatite C
- Syphilis
- CRP
- ASLO

### Parasitologie
- GE/FM (Paludisme)
- KAOP (Kyste, Oeuf, Parasite)
- Bilharziose urinaire

### Biochimie
- Glycémie
- Urée
- Créatinine
- Transaminases
- Etc.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- jsPDF (export PDF)

## 🚀 Installation

1. Cloner le projet :
git clone https://github.com/votre-utilisateur/lab-results-app.git

2-Ouvrir le dossier du projet.
3-Lancer l'application dans un navigateur.
📖 Utilisation
Entrer les informations du patient.
Choisir le domaine d'analyse.
Sélectionner les examens demandés.
Saisir les résultats.
Exporter le compte rendu PDF.
🎯 Objectif du projet
Créer un outil simple, rapide et accessible permettant aux laboratoires de gérer efficacement les résultats d'analyses médicales.
